# Smart Campus AI Assistant — Full Project

An integrated beginner-friendly project covering Data Science, Machine Learning, NLP, Generative AI, RAG, Agentic AI and a Streamlit interface.

## Features
1. Student analytics dashboard with Pandas charts.
2. Decision Tree performance-category demo.
3. Keyword-based feedback sentiment analysis.
4. Optional Gemini academic chatbot.
5. PDF text extraction + TF-IDF retrieval + optional Gemini answer (introductory RAG).
6. Explainable tool-using study-plan workflow.
7. Sample CSV dataset.

## Setup — Windows PowerShell
Python 3.11 is recommended.

```powershell
py -3.11 -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

If activation is blocked, run:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Open `http://localhost:8501` if the browser does not open automatically.

## Optional Gemini setup
1. Copy `.env.example` to `.env`.
2. Add your own key: `GEMINI_API_KEY=your_key_here`
3. Save and restart Streamlit. Never share or commit `.env`.

## Dataset columns
`student_id, course, marks, attendance, assignments`
Marks, attendance and assignments are percentages from 0 to 100. Use fictional or anonymised data.

## Important limitations
- Dataset is fictional and small; model accuracy is not evidence of real-world performance.
- The ML target is generated by a simple formula for teaching classification.
- Sentiment uses keywords and can miss context, negation or sarcasm.
- PDF retrieval uses TF-IDF rather than a vector database; it is an introductory RAG implementation.
- The agent is a predefined explainable tool workflow, not a fully autonomous multi-agent system.
- Scanned PDFs require OCR and are not readable by this PDF text extractor.
- Never use this demo for real admissions, grading, discipline or other high-impact student decisions.

## Troubleshooting
- If `py` is not recognised, install Python and enable Add Python to PATH.
- If Streamlit is missing, activate `.venv` and rerun `pip install -r requirements.txt`.
- Gemini failures usually relate to key, quota, model access or connectivity; other modules work locally.
- For another port: `streamlit run app.py --server.port 8502`.
